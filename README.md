# draw & more

Маленький набір ігор для двох гравців у браузері. Працює на телефоні й комп'ютері, без збірки та залежностей: звичайні HTML-файли.

## Ігри

| Гра | Опис |
|---|---|
| 🖼️ Одна картинка | Обоє малюють одне слово, потім оцінюють малюнки одне одного. Бали за оцінку плюс бонус за швидкість. |
| 🕵️ Вгадай малюнок | У кожного своє слово. Ти малюєш, інший вгадує. |
| 🔄 Естафета | 30 секунд малюєш, і малюнки міняються місцями. 5 раундів, у кінці спільний малюнок. |
| 🔤 Вгадай слово | Питання зверху, відповідь у квадратиках. Відкривайте літери по черзі або одразу вгадуйте слово. |
| 🐊 Крокодил | Один малює слово, другий бачить малюнок наживо й вгадує вголос. Малювальник тисне «вгадав» або «не вгадав», і ролі міняються. |
| 🚢 Морський бій | Поле 10×10, класичний флот із 10 кораблів. Влучання дає ще один постріл. Є реакції-смайлики, міні-карта власного флоту та статистика після гри. |

## Як це працює

1. Обидва гравці заходять у `index.html` і входять за кодом.
2. Один створює гру з 4-значним кодом, другий приєднується за тим самим кодом.
3. У меню обирається гра і її налаштування (раунди, час, категорія слів тощо), потім «почати гру».
4. Обидва пристрої переходять на сторінку гри. Режим і налаштування вибираються лише в меню, на сторінці гри нічого вибирати не треба.

## Файли

| Файл | Призначення |
|---|---|
| `index.html` | Вхід, кімнати, головне меню, гра «вгадай слово» |
| `draw.html` | Малювання: одна картинка, вгадай малюнок, естафета |
| `crocodile.html` | Крокодил |
| `battleship.html` | Морський бій |
| `IMG_2010.jpeg` | Іконка для ярлика на домашньому екрані iOS |

Сторінки обмінюються даними через `localStorage` (`dm_user`, `dm_room`, `dm_slot`, `dm_launch`), тому `draw.html`, `crocodile.html` і `battleship.html` потрібно відкривати з меню, а не напряму.

## Запуск

Проєкт статичний, його можна розмістити на GitHub Pages:

1. **Settings → Pages**.
2. Source: **Deploy from a branch**, гілка `main`, папка `/ (root)`.
3. Відкрий посилання на `index.html` на обох пристроях.

Локально достатньо відкрити `index.html` у браузері. Для кращої поведінки краще запускати через локальний сервер, наприклад `python3 -m http.server`.

## Особливості

- Інтерфейс українською, світла й темна тема.
- Гравці бачать дії одне одного в реальному часі, таймери в обох збігаються.
- Інтерфейс розрахований насамперед на телефон.
